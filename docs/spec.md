# 仕様書（仮題：彩霊のみち）v0.9

最終更新：2026-10-09。数値はすべて仮で、バランス調整で変える前提です。
「実装用の補足」と書いた項目は、実装の曖昧さをなくすために足した決まりです。

## 1. コンセプト

3体のチームで分岐マップを進み、勝つたびに強化を1つ選んで育てていく、読み合いのコマンドバトル。縦持ち片手で、1ランを15〜20分で遊び切れる長さにする。

- 狙う体験：相手の次の一手を読み、相性と交代で上を取る気持ちよさを、毎回違うチーム構成で味わう
- 1戦：1〜2分（8〜12ターン程度）
- 1ラン：15〜20分（3エリア、戦闘12〜15回）
- 負けたら最初から。ラン終了ごとに、次回の選択肢が少しずつ増える
- 対戦相手：CPUのみ。オンライン対戦はリリース後に検討する
- 世界観（8）：和風。色がくすんでいく国で、色の精「彩霊（さいれい）」を連れて旅をする。ボスは色をくすませている「くすみ」の主たち

## 3. バトルルール

### 3.1 基本

- お互い1体ずつ場に出し、毎ターン同時にコマンド（技 または 交代）を選び、行動順に解決する
- 命中は100%固定（外れはない）
- 相手を全員倒せば勝ち。自分のチームが全員倒れたら負け（ラン終了）

### 3.2 能力値

| 能力 | 役割 | 目安 |
| --- | --- | --- |
| HP | 0で戦闘不能 | 80〜120 |
| 攻撃 | 与えるダメージ | 30〜70 |
| 防御 | 受けるダメージ | 30〜70 |
| 素早さ | 行動順 | 30〜70 |

特殊攻撃・特殊防御の区別はない。

### 3.3 属性相性

6属性を円に並べる。並び順：紅 → 橙 → 黄 → 翠 → 蒼 → 紫 →（紅に戻る）

- 時計回りに2つ先までに有利（×1.5）
- 反時計回りに2つ前までに不利（×0.7）
- 真向かいと同じ属性は等倍（×1.0）
- 技の属性と使うキャラの属性が同じなら「共鳴」で ×1.2

実装用の補足：属性の番号を 紅=0, 橙=1, 黄=2, 翠=3, 蒼=4, 紫=5 とし、`d = (守る側 − 攻める側 + 6) % 6` とすると、d が 1・2 なら ×1.5、4・5 なら ×0.7、0・3 なら ×1.0。

相性表（行＝技の属性、列＝受ける側の属性）：

| 攻＼守 | 紅 | 橙 | 黄 | 翠 | 蒼 | 紫 |
| --- | --- | --- | --- | --- | --- | --- |
| 紅 | 1.0 | 1.5 | 1.5 | 1.0 | 0.7 | 0.7 |
| 橙 | 0.7 | 1.0 | 1.5 | 1.5 | 1.0 | 0.7 |
| 黄 | 0.7 | 0.7 | 1.0 | 1.5 | 1.5 | 1.0 |
| 翠 | 1.0 | 0.7 | 0.7 | 1.0 | 1.5 | 1.5 |
| 蒼 | 1.5 | 1.0 | 0.7 | 0.7 | 1.0 | 1.5 |
| 紫 | 1.5 | 1.5 | 1.0 | 0.7 | 0.7 | 1.0 |

### 3.4 ダメージ計算

```
ダメージ = floor(威力 × (攻撃 ÷ 防御) × 相性 × 共鳴 × 乱数 × 0.5)
乱数 = 0.90〜1.00 の一様乱数
最低 1 ダメージ
攻撃・防御は能力変化を反映した値を使う
```

テスト用の計算例：威力60、攻撃=防御、等倍、共鳴なし → 27〜30ダメージ（乱数0.90で27、1.00で30）。

実装用の補足：乱数は 0.90, 0.91, …, 1.00 の11段階から等確率で選ぶ（連続した値にすると 1.00 がちょうど出ず、計算例の「1.00で30」にならないため）。

### 3.5 行動順

1. 交代
2. 先制技
3. それ以外の技：素早さが高い順。同じならランダム（シード付き乱数で決める）

素早さは能力変化と状態異常を反映した値で、毎ターン比べ直す。

実装用の補足：両方が先制技を選んだときは、その2つの間で素早さ順（同じならランダム）。

### 3.6 技

- 1体につき4技まで。種類は攻撃技、補助技（能力変化・回復・状態異常）、先制技の3つ
  - 実装用の補足：補助技はダメージを与えず、効果を順番に適用する。能力変化は「自分か相手」の能力を技ごとに決めた段階数だけ変える（上下3段階で止まる）。回復は自分の最大HPの決まった割合（切り捨て、最低1。最大HPは超えない）。状態異常は相手にかける（命中100%なので必ずかかる。すでに状態異常があれば効かない）。行動順は通常の技と同じく素早さ順
- 威力の目安：通常の技50〜70、大技90〜110、先制技30〜40
- 使用回数の制限はない
- 大技は使ったあと2ターン使えない（実装用の補足：Nターン目に使ったら、N+1とN+2ターン目は選べず、N+3ターン目から選べる）
- 各キャラは、大技以外の技を1つ以上覚える（大技が使えない間に、選べる技がなくならないようにするため）
- 実装用の補足（M5 の技36個）：属性ごとに6つ。通常の技（威力60）、強い通常の技（威力70。主に報酬で覚える）、大技（威力100）、先制技（威力35）、補助技2つ。補助技は次のとおり

  | 属性 | 補助技 |
  | --- | --- |
  | 紅 | 闘志（自分の攻撃↑2）、火照り（自分の攻撃↑1・素早さ↑1） |
  | 橙 | 構え（自分の防御↑2）、手当て（HP 30% 回復） |
  | 黄 | 早駆け（自分の素早さ↑2）、目くらまし（相手の攻撃↓1） |
  | 翠 | 足止め（相手を鈍化）、芽吹き（HP 20% 回復・自分の防御↑1） |
  | 蒼 | 崩し（相手の防御↓1）、静水（自分の防御↑1・相手の素早さ↓1） |
  | 紫 | 蝕み（相手を侵蝕）、朧（自分の防御↑1・相手の攻撃↓1） |

- 実装用の補足（M5 のキャラ12体）：属性ごとに2体。1体目は M2 からの基本のキャラ、2体目は役割を変えたキャラ（例：紅の2体目は、遅くて硬い）。名前・能力・技は `src/data/fighters.ts`、技は `src/data/moves.ts` にまとめる

### 3.7 能力変化

- 1段階ごとに ×1.25（下降は ×0.8）、上下3段階まで
- 交代するとリセット

### 3.8 状態異常

1体につき1つまで。すでにかかっていれば上書きしない。

| ID | 名前（仮） | 効果 | 持続 |
| --- | --- | --- | --- |
| erosion | 侵蝕 | ターン終了時に最大HPの10%ダメージ（切り捨て、最低1） | 3ターン |
| slow | 鈍化 | 素早さ ×0.5 | 2ターン |

実装用の補足：状態異常は補助技でかける。持続ターンは、かかったターンから数える。Nターン目にかかった場合、侵蝕は N・N+1・N+2 ターン目の終了時にダメージを受けて治る。鈍化は N・N+1 ターン目に効き、N+1 ターン目の終了時に治る（N ターン目は行動順が決まったあとなので、実際に遅くなるのは N+1 ターン目）。

### 3.9 交代

- 控えと交代すると、そのターンの行動は終わり。交代は他の行動より先に行われる
- 倒されたあとの交代はターンを使わない
- 交代すると能力変化はリセット、状態異常は残る

### 3.10 1ターンの処理順（実装用の補足）

1. 双方のコマンドを確定する
2. 交代を実行する（両方が交代なら素早さ順）
3. 技を行動順に実行する。順番が来たときに倒れていたら行動しない
4. ターン終了処理：侵蝕のダメージ → 状態異常と大技の使用不可ターンの残りを1減らす。侵蝕のダメージは素早さ順に1体ずつ処理する（同じならシード付き乱数で決める）。ターン終了処理は場にいるキャラだけに行う（控えにいる間は、状態異常と大技の使用不可ターンの残りは減らず、侵蝕のダメージも受けない）
5. 倒れたキャラがいれば、控えから次を選ぶ（ターンを使わない）。控えがいなければ勝敗が決まる。両方の陣営が同じターンに全員倒れた場合は、後に倒れた側の勝ち（先に倒れた側の負け）

## 4. ローグライト進行

1ランは3エリア。各エリアは分岐マップを進み、最後にボスがいる。HPは戦闘をまたいで持ち越し、回復できるのは休憩マスとお守りの効果だけ。

### 4.1 1ランの流れ

1. スタート：候補5体から3体を選んでチームを作る
2. マップ：各エリアは下から上へ進む分岐マップ。次のマスを2〜3択から選ぶ
3. 戦闘に勝つと、報酬を3択から1つ選ぶ
4. エリアの最後でボス戦。勝つと次のエリアへ
5. チームが全員倒れたらラン終了。3エリア目のボスを倒せばクリア

実装用の補足：
- チームの並び順が、戦闘に出る順になる（先頭のキャラから場に出る）
- 戦闘をまたいで持ち越すのはHPだけ。能力変化・状態異常・大技の使用不可は、戦闘ごとにリセットする
- 戦闘で倒れたキャラは、その戦闘に勝ったあと最大HPの10%（切り捨て、最低1）で戻る（8. 未決の仮決め）
- エリア1・2のボスに勝ったら報酬を2回選び、次のエリアの新しいマップ（1層目の手前）へ進む。チーム・HP・お守りはそのまま持ち越す。エリア3のボスに勝てばクリア（報酬はない）

### 4.2 マスの種類

| マス | 内容 | 1ルートで通る回数 |
| --- | --- | --- |
| 戦闘 | 通常のCPU戦（相手1〜3体） | 3〜4 |
| 強敵 | 強いCPU戦。報酬を2回選べる | 0〜1 |
| 休憩 | 全員のHPを30%回復するか、技を1つ強化するかの2択 | 1 |
| スカウト | 候補3体から1体を選び、チームの1体と入れ替える | 1 |
| イベント | 文章の選択肢でリスクとリターンを選ぶ | 0〜1 |
| ボス | エリアの最後。決まった行動パターンを持つ | 1 |

実装用の補足：
- 相手のチーム（仮）：相手は全キャラから重ならないように選ぶ（自分のチームと同じキャラが出ることもある）。能力はエリアの倍率に、強敵の倍率をかけ合わせて、HP・攻撃・防御を強くする（四捨五入。素早さは変えない）。数値は `src/engine/constants.ts` にまとめる

  | | エリア1 | エリア2 | エリア3 |
  | --- | --- | --- | --- |
  | 戦闘マスの人数（1〜5層目） | 1・1・1・1・2 | 1・2・2・2・2 | 2・2・2・3・3 |
  | 強敵の人数 | 2 | 3 | 3 |
  | エリアの倍率 | ×1.0 | ×1.1 | ×1.2 |

  強敵は さらに ×1.1
- ボス（仮）：エリアごとに決まったボスが1体で出る。ボスはスタートの候補・スカウト・ふつうの相手には出ない。1体で3体と戦うので、能力は目安（3.2）より大きい（データは `src/data/fighters.ts` と `src/data/bosses.ts`）
- 休憩：「全員のHPを最大HPの30%（切り捨て、最低1）回復」か「技を1つ強化」を選ぶ。技の強化は、キャラと攻撃技を1つ選んで威力 +10（補助技は選べない。同じ技を何度でも強化できる）
- スカウト：チームにいないキャラから、重ならないように候補を3体出す。1体を選び、チームのだれと入れ替えるかを選ぶ。入った仲間はHP満タンで、抜けたキャラの位置（出る順）に入る。抜けたキャラは戻らない。入れ替えずに進むこともできる
- イベント：イベントの中から1つがランダムに決まる。選択肢には、起きることをそのまま書く。効果はHPの回復・ダメージ（イベントでは倒れない。HPは1より下がらない）・能力強化（報酬と同じ量）と、確率で結果が変わる賭け。対象は全員・先頭・ランダムな1体。選んだあとに結果を見せて、マップに戻る。M4 では仮のイベントを3つ作る

### 4.3 マップ生成（MVP、実装用の補足）

1エリアは下から順に次の層で作る。各層は2〜3マス。隣り合う層のマスを、交差しすぎないようにつなぐ。

1. 戦闘
2. イベント・戦闘・強敵のどれか
3. スカウト または 戦闘
4. 3層目で選ばなかったほう（同じ列の中で、スカウトと戦闘が1回ずつになるようにつなぐ）
5. 戦闘
6. 休憩（全ルートが合流）
7. ボス

これで、どのルートでも戦闘3〜4回、スカウト1回、休憩1回を通る。マップはシード付き乱数で生成する。

- 1〜5層目のマス数は、層ごとに2〜3からランダムに決める（4層目は3層目と同じ数）。休憩とボスは1マス
- 2層目のマスは、イベント・戦闘・強敵から重ならないように選ぶ（同じ種類ばかりにならないようにするため）
- 隣り合う層をつなぐ線は交差させない。3層目と4層目は同じ列のマスどうしをつなぐ。そのため、次のマスが1つしかない（選べない）こともある

### 4.4 戦闘後の報酬（3択から1つ）

- 新しい技を覚える。4枠が埋まっていれば入れ替え
- 能力強化：1体の能力を1つ、10%前後上げる
- お守り（仮）：チーム全体にかかる常時効果。例：先制技の威力+20%、交代したときにHP5%回復
  - M4 では、この例の2つだけを作った。M5 で20個にした（下の表。名前と数値は仮）

実装用の補足：
- 3択は「技・能力強化・お守り」を1つずつ出す。覚えられる技がない、またはお守りを全部持っているときは、その分を別の能力強化にする
- 技：チームのだれかがまだ覚えていない技から1つ。選んだあとに、覚えさせるキャラを選ぶ（もう覚えているキャラは選べない）。4つ覚えていれば忘れる技も選ぶ。大技だけになる入れ替えはできない（3.6）
- 能力強化：チームのだれの・どの能力（最大HP・攻撃・防御・素早さ）かは、選択肢を出すときに決まる。上がる量はいまの値の10%（四捨五入、最低1）。最大HPが上がったときは、いまのHPも同じだけ増える
- お守りの「先制技の威力+20%」は、威力に掛けて切り捨てる（35 → 42）。「交代したときにHP5%回復」は、交代で場に出たキャラ（倒れたあとに控えから出したときも）が、最大HPの5%（切り捨て、最低1）回復する。HPが満タンなら何も起きない
- お守り20個（M5。名前は和風の世界観での仮置き、数値は仮）：

  | お守り | 効果 |
  | --- | --- |
  | 先手のお守り | 先制技の威力 +20% |
  | 鍛錬のお守り | 通常の技の威力 +7% |
  | 渾身のお守り | 大技の威力 +15% |
  | 紅・橙・黄・翠・蒼・紫のお守り（6個） | その属性の技の威力 +15% |
  | 背水のお守り | HPが最大HPの30%以下のとき、攻撃技の威力 +25% |
  | 受け流しのお守り | 相手の技が有利な相性のとき、受けるダメージ -10% |
  | 堅守のお守り | 大技で受けるダメージ -10% |
  | 入れ替えのお守り | 交代で場に出たキャラのHPを、最大HPの5% 回復 |
  | 息吹のお守り | ターンの終わりに、場のキャラのHPを最大HPの3% 回復 |
  | 養生のお守り | 回復技の回復量 +50% |
  | 清めのお守り | 侵蝕にならない |
  | 身軽のお守り | 鈍化にならない |
  | 気力のお守り | 大技の使えないターンが1ターン短くなる |
  | 凱旋のお守り | 戦闘に勝つと、全員のHPを最大HPの10% 回復 |
  | 湯治のお守り | 休憩で回復する量が、最大HPの30% → 50% になる |

- お守りの計算（実装用の補足）：
  - 威力を上げるお守り（技の種類・属性・HPが少ないとき）は、当てはまるものの割合を足してから、威力に掛けて切り捨てる（例：先手と翠のお守りで、翠の先制技35は ×1.35 で47）。HPの条件は、技を使うときのHPで見る
  - 受けるダメージを減らすお守りは、ダメージ式（3.4）の結果に掛けて切り捨てる（最低1）。両方当てはまれば割合を足す
  - ターンの終わりの回復は、侵蝕のダメージのあとに行う（侵蝕で倒れたキャラは回復しない）。HPが満タンなら何も起きない
  - 状態異常を防ぐお守りがあると、相手の補助技の状態異常は効かない（「お守りで防いだ」と出す）
  - 回復技の回復量は、最大HP × 技の割合 × (100 + お守りの割合) ÷ 10000（切り捨て、最低1）。お守りによる回復には効かない
  - 大技の使えないターンが0になるなら、続けて使える
  - 戦闘に勝ったときの回復は、倒れていたキャラが戻った（10%）あとに行う。最大HPは超えない
  - CPU の見積もり（6）にも、両方の陣営のお守りを反映する
- 報酬は必ず1つ選ぶ（受け取らない選択肢はない）。選択肢をタップして「決定」の2タップで受け取る
- ボスに勝ったあとは、ランが終わるので報酬はない

### 4.5 メタ進行（ランをまたぐ成長）

- ラン終了時、到達したところに応じて「記録」ポイントを得る
- ポイントで解放するもの：スタート候補のキャラ、お守りの種類、高難易度モード
- 能力値が直接上がる成長は入れない

## 5. 縦持ち片手UI

操作はすべて画面下半分に集め、上半分は見るだけにする。

画面の上から順に：

1. 相手キャラとHP
2. 自分キャラとHP、状態異常
3. ログ（1行）
4. ここから下が操作領域：技ボタン 2×2
5. 控え2体のアイコンとメニュー

- 技ボタン：属性の色、威力、いまの相手に対する有利・不利のマークを表示。長押しで詳細
- 交代：控えのアイコンをタップ→確定の2タップ（実装用の補足：倒れたあとに控えを出すときも同じ2タップ）
- 行動順の予告：相手の素早さが分かっていれば「先に動ける／後になる」を表示
  - 実装用の補足：「分かっている」＝同じバトルで、その相手キャラと同じ段階の技どうし（どちらも先制技、またはどちらも先制技以外）で行動順を比べたことがある。比べるのは能力変化と鈍化を反映したいまの素早さ。分からない相手には「？」を出す
- HP：自分も相手も、バーと数字（例：72 / 100）で見せる
- 演出：タップで早送り、2倍速の切り替えあり。1ターンの演出は2秒以内
- マップ画面：下から上へ進む縦スクロール。次のマスは画面下側で選ぶ
- 中断と再開：毎ターン自動保存。アプリを閉じても同じターンから再開できる
  - 実装用の補足：保存先はブラウザの localStorage。画面が変わるたびに、ランの状態（戦闘中はバトルの状態と乱数の状態も）を保存する。選びかけの選択（報酬を選んでいる途中など）は保存しない。演出の途中で閉じたときは、演出が終わったあとの状態から再開する。ランが終わったら消す。保存したランがあれば、トップ画面に「つづきから」と「はじめから」を出す（「はじめから」は保存したランが消えるので、確認してから始める）。読めないセーブは捨てる
- 文字は14px以上、タップ領域は44×44px以上

## 6. CPUの思考

| 段階 | 考え方 | 使う場所 |
| --- | --- | --- |
| 1 | 予想ダメージが最大の技を選ぶ | エリア1 |
| 2 | 不利な相手なら控えと交代する。HPが少なければ補助技も検討する | エリア2 |
| 3 | プレイヤーの交代や先制技を予想し、2手先までの損得で選ぶ | エリア3、強敵 |
| ボス | 決まった行動パターン＋条件分岐（例：HPが半分を切ったら大技） | 各エリアのボス |

ボスの次の行動は予告しない。

M4（エリア1だけ）では、強敵とボスも段階1で動かし、相手の人数と能力の倍率で強くする（4.2 の補足）。段階2・3とボスの行動パターンは、エリアが増える M5 で作る。

実装用の補足（段階2）：
- 「不利」は、いまの対面でお互いに一番ダメージの出る技を撃ち合ったとき（予想ダメージ、素早さ順）に負けると見積もること
- 不利なら、相手の攻撃を1回受けてからの撃ち合いでも勝てる控えのうち、一番よいものと交代する
- そういう控えがいなくて、回復技で撃ち合いに勝てるようになるなら回復する。どちらでもなければ段階1と同じ技を選ぶ
- 倒れたあとは、撃ち合いの見込みが一番よい控えを出す

実装用の補足（段階3）：
- 自分のコマンドの候補（技・交代）と、プレイヤーのコマンドの候補（技・交代）のすべての組み合わせについて、1ターンをエンジンで計算する（1手目）。そのあとの状態を「HPの差（倒れたキャラは1体ごとに減点）＋次の撃ち合いの見込み」で点数にする（2手目）
- プレイヤーがこちらにとって一番困る返し方をしてくる前提で、点数が一番よいコマンドを選ぶ（自動対戦で比べて、これが一番強かった）
- 見積もりには固定の乱数を使い、本当の乱数（このあと出るダメージ）は見ない
- 使っても何も起きない補助技（満タンでの回復など）は候補から外す（くり返して勝負がつかなくなるのを防ぐ）
- 相手の場のキャラを、いま選べる攻撃技で確実に（乱数が一番低くても）倒せるときは、補助技を候補から外す（1手先までしか読まないので、倒したあとに出てくる控えを嫌って、倒さずに回復をくり返すことがあるため）
- 段階ごとの強さ（自動対戦）：段階2は段階1に約60%、段階3は段階2に約55%・段階1に約59%勝つ（キャラ12体。6体のときは約70%・約60%・約75%だった）
- 使う場所：エリア1は段階1、エリア2は段階2、エリア3は段階3。強敵はどのエリアでも段階3。ボスは行動パターンで動く

実装用の補足（ボス）：
- 行動パターンはデータで書く。「条件分岐」を上から順に見て、条件がすべて当てはまり、その技が使えるなら使う。どれも当てはまらなければ「決まった順の技」をターンごとに使う（使えない技は飛ばす）
- 条件は「自分のHPが○%未満」「○ターンごと」「相手に状態異常がない」「自分の能力変化が○未満」の組み合わせ
- ボス3体（名前は仮置き）：

  | エリア | ボス | 行動パターン |
  | --- | --- | --- |
  | 1 | くすみ大猿（紅） | 2回殴って大技。HPが半分を切ると攻撃を上げ、大技を使えるときは必ず使う |
  | 2 | くすみ大鯉（蒼） | 状態異常のない相手には侵蝕をかける。HPが35%を切ると回復する |
  | 3 | くすみの主（紫） | 3ターンごとに鈍化をかける。先制技もまぜて攻め、HPが半分を切ると大技を使えるときは必ず使う |


実装用の補足：段階1の「予想ダメージ」は、乱数を真ん中（0.95）にしたダメージ（相性・共鳴・能力変化を反映）。同じなら技の並び順で先のもの。段階1は交代と補助技を使わない（選べる攻撃技がないときだけ、選べる技の先頭を使う）。倒れたあとは、相手の場のキャラに一番ダメージを出せる控えを出す（同じならチームの並び順で先）。

## 8. 決定事項と未決事項

決定済み：

- 命中は100%固定
- 大技は使用回数ではなく、使ったあと2ターン使えない方式
- スタート時は候補5体から3体を選ぶ
- ボスの次の行動は予告しない
- 1ランの長さは15〜20分
- 絵の作風はドット絵
- ダメージの乱数は 0.90〜1.00 の 0.01 刻み（11段階）（3.4）
- 両方が先制技なら素早さ順（3.5）
- 各キャラは大技以外の技を1つ以上覚える（3.6）
- 両方の陣営が同じターンに全員倒れたら、後に倒れた側の勝ち。侵蝕のダメージは素早さ順に処理する（3.10）
- 控えにいる間は、状態異常と大技の使用不可ターンの残りは減らない（3.10）
- 状態異常は補助技でかける。持続ターンはかかったターンから数える（3.8）
- CPU（段階1）は、倒れたら相手に一番ダメージを出せる控えを出す（6）
- 行動順の予告は、同じバトルでその相手と同じ段階の技どうしで比べたあとに出す（5）
- 相手のHPもバーと数字で見せる（5）
- M4 では強敵とボスも段階1で動かし、人数と能力の倍率で強くする。段階2・3とボスの行動パターンは M5（6）
- M4 のお守りは「先制技の威力+20%」と「交代したときにHP5%回復」の2つ（4.4）
- 休憩の技の強化は、攻撃技1つの威力 +10（4.2）
- スカウトは断れる（入れ替えずに進める）（4.2）
- エリア1・2のボスに勝ったら、報酬を2回選んで次のエリアへ（4.1）
- メタ進行（4.5）は M5 には入れない。遊んでみて必要になったら M6 の前に入れる
- ドット絵は、用意してもらった絵を縮小・減色して組み込む。採用はA案（GPT Image 2.5）で、4枚は描き直したもの（5.1）
- お守りは20個。技の種類・属性・HPの条件で威力を上げるもの、受けるダメージを減らすもの、回復、状態異常よけ、大技、ラン全体に効くものを組み合わせる（4.4）
- 世界観は和風に決定（1）。仮題は「彩霊のみち」、属性名は色の名前（紅・橙・黄・翠・蒼・紫）のまま。キャラ名・技名・ボス名・タイトルは仮で、データ側（`src/data/`）だけで差し替えられる。絵（M5-7）は和風で描く（5.1）

- 戦闘で倒れたキャラを次の戦闘でどう扱うか。仮：勝利後にHP10%で復帰（M4 はこの仮決めで作る）
